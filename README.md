# Multi-Tenant SaaS Dashboard

A full-stack SaaS dashboard built with React and Spring Boot, designed to support multiple organizations with secure tenant-based access.

## ✨ Features

### 🔐 Authentication & Security

- User registration and login
- JWT-based authentication
- Role-based access control
- Protected routes
- Separate admin authentication
- Secure tenant-aware request handling

### 🏢 Multi-Tenant Architecture

- Organization/tenant-based data isolation
- Tenant-aware API requests
- Secure tenant context management
- Users are associated with their respective organizations
- Shared backend infrastructure with logical tenant separation

### 👥 Member Management

- Add and manage organization members
- Member profiles
- Role-based permissions
- Member invitation system
- Profile management

### 📊 Dashboard & Analytics

- Organization dashboard
- Analytics tracking
- Activity/event logging
- Attendance statistics
- Tenant-specific analytics

### 📅 Attendance Management

- Attendance records
- Attendance tracking
- Organization-level attendance data
- Attendance analytics

### 💬 Real-Time Chat

- Tenant-based communication
- Real-time messaging
- WebSocket-based communication
- Chat history

### 👨‍💼 Admin & Super Admin

- Admin dashboard
- Super Admin controls
- Tenant management
- Administrative authentication
- Organization-level management
